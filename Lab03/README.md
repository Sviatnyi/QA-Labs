- [`report.pdf`](report.pdf) — звіт
- [`screenshots/`](screenshots/) — скриншоти до звіту
- [`configs/`](configs/) — `dhcpd.conf` (еталонний) і `dhcpd-wrong-router.conf` (з дефектом)
- [`captures/`](captures/) — захоплення DHCP-трафіку `.pcap` (відкриваються у Wireshark)
- [`logs/`](logs/) — вивід клієнта, розшифровки захоплень, `dhcpd.leases`, журнал сервера
